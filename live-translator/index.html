📱 ቀጥታ ትርጉም v1.5

የቀጥታ ትርጉም app — YouTube ቪዲዮን በእንግሊዝኛ (ወይም አረብኛ፣ ስፓኒሽ፣ ቻይንኛ፣ ሩሲያኛ፣ ዕብራይስጥ፣ ጀርመን) እያዳመጥክ በአማርኛ ይተረጉምልሃል።

ስሪት፦ 1.5  •  መጠን፦ 22.25 MB  •  ለ Samsung A03s (armv7)

እንዴት እንደምትጭን

  1. የድሮውን “ቀጥታ ትርጉም” app መጀመሪያ አራግፍ (Settings → Apps → ቀጥታ ትርጉም → Uninstall)።
  2. ከላይ ያለውን አውርድ ቁልፍ ጫን — download እስኪጠናቀቅ ጠብቅ።
  3. የወረደውን ፋይል ጫን → Install ጫን።
  4. “Play Protect” ካስጠነቀቀ Install anyway ጫን።
  5. App drawer ውስጥ አረንጓዴ iconውን (“ቀጥታ ትርጉም”) ፈልግ — ወይም “ቀጥታ” ብለህ ፈልግ።
