//@version=5

// AMANDIRE S&R ZONE DETECTOR — v1.4 DRAFT (research draft on top of Selam's v1.6 LIGHT)
// *** DRAFT — NOT the live file. Live file is v1.6 (amandire_sr_zone_detector.pine).
// *** Do NOT overwrite v1.6 or the live copy page with this file.
// *** Keeps all of v1.6 LIGHT: "Bars to calculate" window, labels drawn only
//     on the last bar, MTF visibility re-checked only on HTF change.
// What is new vs v1.6 (28 Nov 2026, deep-research v2):
//   1. MEASURED DEFAULTS: pivot length 65, half-width 1.0 x ATR (was 10 / 0.5).
//      This is the best honestly-measured configuration from the backtest
//      (chart-TF engine, pivot 65 + half-width 1.0, 1-close break, 8 zones/side):
//        gold 1m tuning  Sep-Nov 2026: respect 74.84%, touch win-rate 52.60%,
//            big-move (>=2 ATR in 10 bars after first touch) 60.97% (n=433)
//        gold 1m FRESH    Jun-Sep 2026: respect 73.76%, touch win-rate 56.29%,
//            big-move 57.06% (n=545)
//        BTC  1m tuning  Sep-Nov 2026: respect 73.86%, touch win-rate 57.14%,
//            big-move 60.38% (n=578)
//      Base (pivot 10 / 0.5) for comparison: respect 66.45/65.10/68.30%,
//      touch win-rate 35.94/38.48/43.87%, big-move 52.13/49.87/50.61%.
//      MTF-only v1.3 numbers were gold 65.8% / BTC 70.1% respect.
//      NOTE: with pivot 65, the first 65 bars of the "Bars to calculate"
//      window produce no zones (confirmation lag, not repainting).
//   2. FORMATION-PLACE MARKERS (display only, never a filter): every zone label
//      now carries its birth tag — pivot candle class (ENGULF/PIN/DOJI/MARU/NORM),
//      base bars (tight bars in the 15 before the pivot), leg size in ATR,
//      rejection wick in ATR, volume ratio, REV (strong close rejection),
//      CCI (CCI(20) extreme at the pivot), W60 (60-min efficiency > 0.31),
//      VWAP (level near session VWAP). Measured truth: NONE of these predicts
//      big moves (best single +2pp, none consistent on both windows) — they are
//      shown so Selam can SEE where each zone was born, not to filter zones.
//   3. PROVEN tag: after a zone's FIRST bounce, the label gains "PROVEN".
//      Measured: next touch after a bounce wins 58.25% / 59.14% / 60.88%
//      (gold tun / gold fresh / BTC, n=451/597/737) vs first-touch 35.94/38.48/
//      43.87%; after TWO bounces 63.84% / 59.73% / 57.84%. BUT the big-move
//      rate does NOT rise (51.44/50.92/46.54%) — PROVEN means "bounces again",
//      not "moves big".
//   4. OB tag (SMC order block): when price breaks structure (close past the
//      last confirmed pivot), the zone at the ORIGIN pivot of that leg is
//      tagged "OB". Measured: OB zones are NOT better — respect 69.75/62.79/
//      68.76%, big-move 52.65/50.14/54.73%; after the BOS they break 60%+ of
//      the time. Shown as information only.
//   5. MSS / FIB touch-time tags: at the FIRST touch the label gains "MSS"
//      (a structure shift in the last 50 bars, same direction) and/or "FIB"
//      (the zone sits within 0.5 ATR of the 1.618 extension of that MSS leg,
//      Fib drawn with 0.963 at the MSS point, i.e. x1.6807). Measured: MSS
//      zones are NOT better (no-MSS zones score higher); Fib 1.618 adds
//      +3.1pp respect on gold only, big-move flat. Shown as information only.
//   6. MTF-only default is OFF in this draft (v1.6 default ON). The measured
//      numbers above are CHART-TF engine numbers with no HTF filter; turning
//      MTF-only ON shows a smaller, HTF-agreeing subset whose numbers were
//      NOT measured for this config.
// HONEST CEILING — READ THIS: no birth filter in the whole study reaches
// near-100%. Big-move rate for ANY birth-time filter is ~50-60% (random
// bands score 54.73/51.22/52.51% — zones do NOT beat random bands on big
// moves); the oracle ceiling (knowing the future outcome) is ~55%; the
// best failure separators lift the good-zone share only from ~48/45/49%
// to ~53-60%. ~1/3 of resolved zones are violated, ~70% of those break on
// the FIRST touch with no warning feature in the data. The pivot-65 +
// width-1.0 combination was SELECTED on these same three legs, so its
// numbers are partly selection — a fresh window is needed to confirm them.
// This draft is the best measured configuration, NOT a 100% detector.
// NO-LOOKAHEAD VERIFICATION (bar-by-bar, correction 4):
//   * Zone birth: confirmed pivot only (ta.pivothigh/low with left=right
//     = pivLen); the zone appears pivLen bars AFTER the pivot bar, using
//     ATR/volume/OHLC values read AT the pivot bar ([pivLen] offsets).
//   * Formation tag: every input is a [pivLen] (or deeper) historical
//     offset, or a var tracker updated only on closed bars from confirmed
//     pivots. Nothing reads the current (forming) bar.
//   * MSS/FIB tags: evaluated at the first touch from the last MSS event,
//     which happened strictly before the touch bar.
//   * OB tag: set only when a BOS close has already happened (past bar).
//   * PROVEN tag: set only after a bounce close has already happened.
//   * HTF via request.security(..., lookahead=barmerge.lookahead_off);
//     all logic runs under barstate.isconfirmed (closed bars only) and
//     inside the "Bars to calculate" window (inRange).
//   * The post-touch big move is used ONLY in the Python backtest to
//     MEASURE prediction power; this indicator never uses any future
//     outcome to decide whether to draw a zone.
// Kept from v1.6: LIGHT performance (Bars to calculate, last-bar labels,
// MTF re-check only on HTF change), colour settings, MTF-only view,
// per-timeframe checkboxes, minimum confluence, all hardening (nz rename,
// ATR-na guard, hidden-label fix, HTF-higher-than-chart check, guarded

//
// NON-REPAINTING CONTRACT (unchanged)
//   * Zones are born only from confirmed pivots; frozen once drawn.
//   * Events run on closed bars only (barstate.isconfirmed).
//   * HTF via request.security(..., lookahead_off).
//   * A break = candle BODY close past the far edge; wicks are pierces.
//   * Touch is NEVER an entry by itself. Respect is not a trading edge.
// ============================================================================

// ---------------- Helpers ----------------
zoneCount(_side) =>
    int n = 0
    int sz = array.size(zSide)
    if sz > 0
        for i = 0 to sz - 1
            if array.get(zSide, i) == _side
                n += 1
    n

strengthOf(_i) =>
    float volS = 0.5
    float vAt = array.get(zVol, _i)
    if not na(volSMA) and volSMA > 0 and vAt > 0
        volS := math.min(vAt / volSMA, 3.0) / 3.0
    float tS = math.min(array.get(zTouches, _i) / 5.0, 1.0)
    float aS = math.max(1.0 - (bar_index - array.get(zBorn, _i)) / 500.0, 0.0)
    0.40 * volS + 0.30 * tS + 0.30 * aS

confluenceOf(_i) =>
    float top = array.get(zTop, _i)
    float bot = array.get(zBot, _i)
    int c = useChart ? 1 : 0
    for s = 0 to 5
        float ht = array.get(hTop, s)
        float hb = array.get(hBot, s)
        if not na(ht) and not na(hb) and ht >= bot and hb <= top
            c += 2
    c

// A chart zone is VISIBLE when MTF-only is off, or its confluence reaches the minimum.
zoneVisible(_i) =>
    not mtfOnly or confluenceOf(_i) >= minConf

// Formation tag for a zone being born NOW. Every input is a historical
// offset ([pivLen] = the pivot bar) or a var tracker holding confirmed
// pivots from earlier bars — nothing reads the forming bar. Mirrors the
// Python backtest definitions (filter_study.py formation_features):
// engulf > pin > doji > marubozu > normal; pin = wick >= 2x body and
// >= 50% of range; base = tight bars (range < 0.5 ATR) in the 15 bars
// BEFORE the pivot; leg = last opposite pivot -> this pivot, in ATR.
formationTag(_side, _level) =>
    float a = atrVal[pivLen]
    float oP = open[pivLen]
    float hP = high[pivLen]
    float lP = low[pivLen]
    float cP = close[pivLen]
    float rng = hP - lP
    float body = math.abs(cP - oP)
    float upW = hP - math.max(oP, cP)
    float dnW = math.min(oP, cP) - lP
    bool prevBull = close[pivLen + 1] > open[pivLen + 1]
    bool prevBear = close[pivLen + 1] < open[pivLen + 1]
    bool curBull = cP > oP
    bool curBear = cP < oP
    bool bullEng = prevBear and curBull and oP <= close[pivLen + 1] and cP >= open[pivLen + 1]
    bool bearEng = prevBull and curBear and oP >= close[pivLen + 1] and cP <= open[pivLen + 1]
    bool engulf = bullEng or bearEng
    bool pin = false
    if rng > 0 and body > 0
        if upW >= 2 * body and upW >= 0.5 * rng
            pin := true
        else if dnW >= 2 * body and dnW >= 0.5 * rng
            pin := true
    bool doji = rng > 0 and body <= 0.1 * rng
    bool maru = rng > 0 and body >= 0.9 * rng
    string cls = engulf ? "ENGULF" : pin ? "PIN" : doji ? "DOJI" : maru ? "MARU" : "NORM"
    float wickAtr = (_side == 1 ? upW : dnW) / a
    float rev = na
    if rng > 0
        rev := _side == 1 ? (hP - cP) / rng : (cP - lP) / rng
    int baseBars = int(nz(ta.sum(tightBar, 15)[pivLen + 1], 0))
    float legAtr = na
    if _side == 1 and not na(lastPlLvl)
        legAtr := (_level - lastPlLvl) / a
    else if _side == -1 and not na(lastPhLvl)
        legAtr := (lastPhLvl - _level) / a
    float volR = na
    if not na(volume[pivLen]) and not na(volSMA[pivLen]) and volSMA[pivLen] > 0
        volR := volume[pivLen] / volSMA[pivLen]
    string tag = cls + "·B" + str.tostring(baseBars)
    tag += "·L" + (na(legAtr) ? "-" : str.tostring(legAtr, "#.#"))
    tag += "·W" + str.tostring(wickAtr, "#.#")
    tag += "·V" + (na(volR) ? "-" : str.tostring(volR, "#.#"))
    if not na(rev) and rev >= 0.67
        tag += "·REV"
    if not na(cciVal[pivLen]) and math.abs(cciVal[pivLen]) >= 100
        tag += "·CCI"
    if not na(w60Val[pivLen]) and w60Val[pivLen] > 0.31
        tag += "·W60"
    if not na(vwapVal[pivLen]) and math.abs(_level - vwapVal[pivLen]) <= 0.5 * a
        tag += "·VWAP"
    tag

labelText(_i) =>
    string side = array.get(zSide, _i) == 1 ? "R" : "S"
    string lvl = str.tostring(array.get(zLvl, _i), format.mintick)
    int sc = math.round(strengthOf(_i) * 100)
    int conf = confluenceOf(_i)
    string weak = array.get(zPierces, _i) >= 3 ? " WEAK" : ""
    string flip = array.get(zFlipped, _i) ? " FLIP" : ""
    string htfTxt = conf > 1 ? " HTF" : ""
    string formTxt = showForm ? " [" + array.get(zForm, _i) + "]" : ""
    string provenTxt = showProven and array.get(zProven, _i) ? " PROVEN✓" : ""
    string obTxt = showOb and array.get(zOb, _i) ? " OB" : ""
    string touchTxt = array.get(zTouch, _i)
    side + " " + lvl + " · T" + str.tostring(array.get(zHits, _i)) + " · P" + str.tostring(array.get(zPierces, _i)) + " · " + str.tostring(sc) + "% · x" + str.tostring(conf) + weak + flip + htfTxt + formTxt + provenTxt + obTxt + touchTxt

// Box colours only (cheap). Label look/text/position is done once, on the last bar.
refreshBox(_i) =>
    box b = array.get(zBox, _i)
    bool vis = zoneVisible(_i)
    color bg = array.get(zSide, _i) == 1 ? resBg : supBg
    color bcol = array.get(zSide, _i) == 1 ? resCol : supCol
    if array.get(zState, _i) == ST_DONE_BAD
        bg := deadBg
        bcol := deadCol
    else if array.get(zFlipped, _i)
        bg := flipBg
        bcol := flipCol
    if vis
        box.set_border_color(b, bcol)
        box.set_bgcolor(b, bg)
    else
        box.set_border_color(b, clearC)
        box.set_bgcolor(b, clearC)

// Label look + text + position — called only on the last bar.
drawLabel(_i) =>
    label l = array.get(zLab, _i)
    bool vis = zoneVisible(_i)
    if vis and showLabels
        int sc = math.round(strengthOf(_i) * 100)
        color bg = array.get(zSide, _i) == 1 ? resBg : supBg
        if array.get(zState, _i) == ST_DONE_BAD
            bg := deadBg
        else if array.get(zFlipped, _i)
            bg := flipBg
        label.set_text(l, labelText(_i))
        label.set_xy(l, bar_index, array.get(zSide, _i) == 1 ? array.get(zTop, _i) : array.get(zBot, _i))
        label.set_color(l, bg)
        label.set_textcolor(l, sc >= strongThr ? labTextIn : color.new(labTextIn, 20))
    else
        label.set_text(l, "")
        label.set_color(l, clearC)
        label.set_textcolor(l, clearC)

// One event label on the chart (only if events are shown and the zone is visible)
addEvent(_i, _txt, _y, _above, _col) =>
    if showEvents and zoneVisible(_i)
        label.new(bar_index, _y, _txt, style=_above ? label.style_label_down : label.style_label_up, color=_col, textcolor=color.white, size=size.small)

// Break: zone flips role (turncoat) and the retest watch opens
flipZone(_i, _side) =>
    array.set(zState, _i, ST_FLIPPED)
    array.set(zMark, _i, bar_index)
    array.set(zSide, _i, -_side)
    array.set(zFlipped, _i, true)
    array.set(zHits, _i, 0)
    if array.get(zFirst, _i) == 0
        array.set(zFirst, _i, 2)
    refreshBox(_i)

removeZone(_i) =>
    box b = array.get(zBox, _i)
    label l = array.get(zLab, _i)
    if not na(b)
        box.delete(b)
    if not na(l)
        label.delete(l)
    array.remove(zTop, _i)
    array.remove(zBot, _i)
    array.remove(zLvl, _i)
    array.remove(zSide, _i)
    array.remove(zState, _i)
    array.remove(zTouches, _i)
    array.remove(zHits, _i)
    array.remove(zPierces, _i)

    array.remove(zVol, _i)
    array.remove(zBox, _i)
    array.remove(zLab, _i)
    array.remove(zMark, _i)
    array.remove(zHold, _i)

    array.remove(zForm, _i)
    array.remove(zProven, _i)
    array.remove(zOb, _i)
    array.remove(zTouch, _i)

addZone(_side, _level, _vol, _form) =>
    // width — ATR frozen at the PIVOT bar so the zone never breathes
    float top = na
    float bot = na
    if widthMode == "Centred"
        top := _level + halfW * atrVal[pivLen]
        bot := _level - halfW * atrVal[pivLen]
    else
        float fuzz = atr7[pivLen] / 2 * fuzzMult
        if _side == 1
            top := _level
            bot := _level - fuzz
        else
            top := _level + fuzz
            bot := _level
    // merge: reinforce an existing same-side zone within mergeDist x ATR
    bool merged = false
    int cnt = array.size(zLvl)
    if cnt > 0
        for i = 0 to cnt - 1
            if not merged and array.get(zSide, i) == _side and math.abs(array.get(zLvl, i) - _level) <= mergeDist * atrVal
                array.set(zTouches, i, array.get(zTouches, i) + 1.0)
                array.set(zHits, i, array.get(zHits, i) + 1)
                merged := true
    if not merged
        // too-close filter: same-side zones within 1 x ATR -> keep the nearer to price
        int dropClose = -1
        bool suppressNew = false
        cnt := array.size(zLvl)
        if cnt > 0
            for i = 0 to cnt - 1
                if array.get(zSide, i) == _side and math.abs(array.get(zLvl, i) - _level) <= atrVal
                    if math.abs(array.get(zLvl, i) - close) < math.abs(_level - close)
                        suppressNew := true
                    else if dropClose == -1
                        dropClose := i
        if not suppressNew
            if dropClose >= 0
                removeZone(dropClose)
            // capacity: drop the oldest UNTESTED same-side zone first
            if zoneCount(_side) >= maxZones
                int drop = -1
                int oldest = 1000000000
                int sz2 = array.size(zSide)
                if sz2 > 0
                    for i = 0 to sz2 - 1
                        if array.get(zSide, i) == _side and array.get(zHits, i) == 0 and array.get(zBorn, i) < oldest
                            oldest := array.get(zBorn, i)
                            drop := i
                    if drop == -1
                        int oldestAny = 1000000000
                        for i = 0 to sz2 - 1
                            if array.get(zSide, i) == _side and array.get(zBorn, i) < oldestAny
                                oldestAny := array.get(zBorn, i)
                                drop := i
                if drop >= 0
                    removeZone(drop)
            color bcol = _side == 1 ? resCol : supCol
            color bbg = _side == 1 ? resBg : supBg
            box nb = box.new(bar_index, top, bar_index + 1, bot, xloc=xloc.bar_index, extend=extend.right, border_color=bcol, bgcolor=bbg)
            label nl = label.new(bar_index, _side == 1 ? top : bot, "", xloc=xloc.bar_index, style=_side == 1 ? label.style_label_down : label.style_label_up, color=clearC, textcolor=clearC, size=size.small)
            array.push(zTop, top)
            array.push(zBot, bot)
            array.push(zLvl, _level)
            array.push(zSide, _side)
            array.push(zState, ST_ACTIVE)
            array.push(zTouches, 0.0)
            array.push(zHits, 0)
            array.push(zPierces, 0)
            array.push(zBounces, 0)
            array.push(zBorn, bar_index)
            array.push(zVol, _vol)
            array.push(zBox, nb)
            array.push(zLab, nl)
            array.push(zMark, int(na))
            array.push(zHold, 0)
            array.push(zRetestBar, int(na))
            array.push(zFirst, 0)
            array.push(zFlipped, false)
            array.push(zForm, _form)
            array.push(zProven, false)
            array.push(zOb, false)
            array.push(zTouch, "")
            refreshBox(array.size(zLvl) - 1)

// ---------------- HTF zone update (latest zone per side per slot) ----------------
// Returns true when an HTF zone was created / replaced (so visibility must be re-checked).
htfUpdate(_slot, _ph, _pl, _atr, _tf) =>
    bool ch = false
    // resistance
    if not na(_ph) and not na(_atr) and (na(array.get(hLastPh, _slot)) or array.get(hLastPh, _slot) != _ph)
        ch := true
        array.set(hLastPh, _slot, _ph)
        int idxR = _slot * 2
        float topR = _ph + halfW * _atr
        float botR = _ph - halfW * _atr
        box obR = array.get(hBox, idxR)
        label olR = array.get(hLab, idxR)
        if not na(obR)
            box.delete(obR)
        if not na(olR)
            label.delete(olR)
        box nbR = box.new(bar_index, topR, bar_index + 1, botR, xloc=xloc.bar_index, extend=extend.right, border_color=htfCol, bgcolor=htfBg)
        label nlR = label.new(bar_index, topR, "HTF " + _tf + " R " + str.tostring(_ph, format.mintick), xloc=xloc.bar_index, style=label.style_label_down, color=htfBg, textcolor=labTextIn, size=size.small)
        array.set(hTop, idxR, topR)
        array.set(hBot, idxR, botR)
        array.set(hBox, idxR, nbR)
        array.set(hLab, idxR, nlR)
    // support
    if not na(_pl) and not na(_atr) and (na(array.get(hLastPl, _slot)) or array.get(hLastPl, _slot) != _pl)
        ch := true
        array.set(hLastPl, _slot, _pl)
        int idxS = _slot * 2 + 1
        float topS = _pl + halfW * _atr
        float botS = _pl - halfW * _atr
        box obS = array.get(hBox, idxS)
        label olS = array.get(hLab, idxS)
        if not na(obS)
            box.delete(obS)
        if not na(olS)
            label.delete(olS)
        box nbS = box.new(bar_index, topS, bar_index + 1, botS, xloc=xloc.bar_index, extend=extend.right, border_color=htfCol, bgcolor=htfBg)
        label nlS = label.new(bar_index, botS, "HTF " + _tf + " S " + str.tostring(_pl, format.mintick), xloc=xloc.bar_index, style=label.style_label_up, color=htfBg, textcolor=labTextIn, size=size.small)
        array.set(hTop, idxS, topS)
        array.set(hBot, idxS, botS)
        array.set(hBox, idxS, nbS)
        array.set(hLab, idxS, nlS)
    ch

// ---------------- HTF data (maths INSIDE the HTF context, lookahead OFF) ----------------
chartSec = timeframe.in_seconds()
ok1 = useHtf1 and timeframe.in_seconds(htf1) > chartSec
ok2 = useHtf2 and timeframe.in_seconds(htf2) > chartSec
ok3 = useHtf3 and timeframe.in_seconds(htf3) > chartSec

[hp1, lp1, at1] = request.security(syminfo.tickerid, ok1 ? htf1 : timeframe.period, [ta.pivothigh(high, pivLen, pivLen), ta.pivotlow(low, pivLen, pivLen), ta.atr(atrLen)[pivLen]], lookahead=barmerge.lookahead_off)
[hp2, lp2, at2] = request.security(syminfo.tickerid, ok2 ? htf2 : timeframe.period, [ta.pivothigh(high, pivLen, pivLen), ta.pivotlow(low, pivLen, pivLen), ta.atr(atrLen)[pivLen]], lookahead=barmerge.lookahead_off)
[hp3, lp3, at3] = request.security(syminfo.tickerid, ok3 ? htf3 : timeframe.period, [ta.pivothigh(high, pivLen, pivLen), ta.pivotlow(low, pivLen, pivLen), ta.atr(atrLen)[pivLen]], lookahead=barmerge.lookahead_off)

// ---------------- Main logic — CLOSED BARS ONLY (no repaint) ----------------
if barstate.isconfirmed and inRange and not na(atrVal)
    // HTF zones first (so confluence counts them)
    bool htfCh = false
    if ok1
        bool c1 = htfUpdate(0, hp1, lp1, at1, htf1)
        htfCh := htfCh or c1
    if ok2
        bool c2 = htfUpdate(1, hp2, lp2, at2, htf2)
        htfCh := htfCh or c2
    if ok3
        bool c3 = htfUpdate(2, hp3, lp3, at3, htf3)
        htfCh := htfCh or c3

    // HTF zones changed: re-evaluate which chart zones the MTF-only view shows
    if mtfOnly and htfCh
        int nz0 = array.size(zLvl)
        if nz0 > 0
            for i = 0 to nz0 - 1
                refreshBox(i)

    // v1.4 draft — MSS / BOS detection (close past the last CONFIRMED pivot).
    // Runs BEFORE new pivots update the trackers, so it uses the pivots as
    // they stood on previous bars. lastMss* holds the most recent MSS event
    // (any direction); Zero = last opposite pivot before the broken pivot.
    bool mssBull = not na(lastPhLvl) and close > lastPhLvl and close[1] <= lastPhLvl
    bool mssBear = not na(lastPlLvl) and close < lastPlLvl and close[1] >= lastPlLvl
    if mssBull or mssBear
        lastMssBar := bar_index
        if mssBull
            lastMssDir := 1
            lastMssZero := prevPlLvl
            lastMssE := lastPhLvl
        else
            lastMssDir := -1
            lastMssZero := prevPhLvl
            lastMssE := lastPlLvl
        // OB tag: the zone born at the ORIGIN pivot of this leg
        if showOb
            int originBar = mssBull ? prevPlBar : prevPhBar
            if not na(originBar)
                int nOb = array.size(zLvl)
                if nOb > 0
                    for j = 0 to nOb - 1
                        if array.get(zBorn, j) - pivLen == originBar and not array.get(zOb, j)
                            array.set(zOb, j, true)

    // New chart-TF zones on confirmed pivots (volume at the PIVOT bar).
    // The formation tag is computed BEFORE the trackers update, so the leg
    // reads the last OPPOSITE pivot (the leg into this pivot).
    if not na(ph) and atrOk
        addZone(1, ph, nz(volume[pivLen], 0), formationTag(1, ph))
        prevPlBar := lastPlBar
        prevPlLvl := lastPlLvl
        lastPhBar := bar_index - pivLen
        lastPhLvl := ph
    if not na(pl) and atrOk
        addZone(-1, pl, nz(volume[pivLen], 0), formationTag(-1, pl))
        prevPhBar := lastPhBar
        prevPhLvl := lastPhLvl
        lastPlBar := bar_index - pivLen
        lastPlLvl := pl

    // Zone state machines
    int nZones = array.size(zLvl)
    if nZones > 0
        for i = 0 to nZones - 1
            int side = array.get(zSide, i)
            int st = array.get(zState, i)
            float top = array.get(zTop, i)
            float bot = array.get(zBot, i)
            bool overlaps = low <= top and high >= bot
            bool hit = close >= bot and close <= top and not (close[1] >= bot and close[1] <= top)
            bool pierce = overlaps and not (close >= bot and close <= top)
            bool bodyBreak = side == 1 ? close > top : close < bot
            bool bodyBreakPrev = side == 1 ? close[1] > top : close[1] < bot
            bool bodyBreakConf = bodyBreak and (breakConfirm == 1 or bodyBreakPrev)
            bool closeOutsideNear = side == 1 ? close < bot : close > top

            if st == ST_ACTIVE
                if hit
                    // touch quality: false break 1.2 / body 0.8 / consolidation 0.5
                    float q = 0.8
                    if side == 1 and high > top and close <= top
                        q := 1.2
                    else if side == -1 and low < bot and close >= bot
                        q := 1.2
                    else if open >= bot and open <= top and close >= bot and close <= top
                        q := 0.5
                    array.set(zTouches, i, array.get(zTouches, i) + q)
                    array.set(zHits, i, array.get(zHits, i) + 1)
                    array.set(zState, i, ST_TOUCHED)
                    array.set(zMark, i, bar_index)
                    // v1.4 draft — touch-time MSS/FIB tags (most recent MSS
                    // BEFORE this touch bar; direction must match the zone
                    // side). Fib 1.618 uses Selam's Fib: 0.963 at the MSS
                    // point, so the level is Zero + (1.618/0.963) x (E - Zero).
                    if array.get(zTouch, i) == "" and not na(lastMssBar) and lastMssDir == side
                        string tt = ""
                        if bar_index - lastMssBar <= 50
                            tt := " MSS"
                        if bar_index - lastMssBar <= 100 and not na(lastMssZero) and not na(lastMssE)
                            float f1618 = lastMssZero + (1.618 / 0.963) * (lastMssE - lastMssZero)
                            if math.abs(array.get(zLvl, i) - f1618) <= 0.5 * atrVal
                                tt += " FIB"
                        if tt != ""
                            array.set(zTouch, i, tt)
                    if strengthOf(i) * 100 >= strongThr
                        if zoneVisible(i)
                            evTouchStrong := true
                else if pierce
                    array.set(zPierces, i, array.get(zPierces, i) + 1)
                // break can also happen without a prior hit on this zone
                if bodyBreakConf
                    addEvent(i, "BREAK", side == 1 ? high : low, side == 1, color.new(color.red, 0))
                    if zoneVisible(i)
                        evBreak := true
                    flipZone(i, side)

            else if st == ST_TOUCHED
                int markBar = nz(array.get(zMark, i), bar_index)
                if closeOutsideNear and bar_index - markBar <= 3
                    // BOUNCE: close back outside within 3 bars
                    addEvent(i, "BOUNCE", side == 1 ? top : bot, side == 1, color.new(color.green, 0))
                    bool firstBounce = array.get(zBounces, i) == 0
                    array.set(zBounces, i, array.get(zBounces, i) + 1)
                    // v1.4 draft — PROVEN tag on the FIRST bounce (past data
                    // only: the bounce close already happened). Measured
                    // next-touch win-rate 58-61% vs 36-44% first touch.
                    if firstBounce and showProven
                        array.set(zProven, i, true)
                    if array.get(zFirst, i) == 0
                        array.set(zFirst, i, 1)
                    array.set(zState, i, ST_ACTIVE)
                    array.set(zMark, i, int(na))
                else if bodyBreakConf
                    addEvent(i, "BREAK", side == 1 ? high : low, side == 1, color.new(color.red, 0))
                    if zoneVisible(i)
                        evBreak := true
                    flipZone(i, side)
                else if bar_index - markBar > 3
                    // touch went stale: zone stays active
                    array.set(zState, i, ST_ACTIVE)
                    array.set(zMark, i, int(na))

            else if st == ST_FLIPPED
                int markBar2 = nz(array.get(zMark, i), bar_index)
                if bar_index - markBar2 > 20
                    // break with no retest in 20 bars = violated
                    addEvent(i, "NO RETEST", side == 1 ? top : bot, side == 1, color.new(color.gray, 0))
                    array.set(zState, i, ST_DONE_BAD)
                    refreshBox(i)
                else if overlaps and bar_index > markBar2
                    // retest: price returned into the flipped zone
                    addEvent(i, "RETEST", side == 1 ? bot : top, side == -1, color.new(color.orange, 0))
                    array.set(zState, i, ST_RETEST)
                    array.set(zRetestBar, i, bar_index)
                    array.set(zHold, i, 0)

            else if st == ST_RETEST
                int rtBar = nz(array.get(zRetestBar, i), bar_index)
                if bar_index > rtBar
                    bool failed = side == 1 ? close < bot : close > top
                    if failed
                        addEvent(i, "RETEST FAILED", side == 1 ? high : low, side == 1, color.new(color.red, 0))
                        array.set(zState, i, ST_DONE_BAD)
                        refreshBox(i)
                    else
                        array.set(zHold, i, array.get(zHold, i) + 1)
                        if array.get(zHold, i) >= 3
                            addEvent(i, "HOLD ✓", side == 1 ? bot : top, side == -1, color.new(color.green, 0))
                            if zoneVisible(i)
                                evRetestHeld := true
                            array.set(zState, i, ST_ACTIVE)
                            array.set(zMark, i, int(na))
